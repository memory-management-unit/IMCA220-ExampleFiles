## TO USE THIS REPO
### Option A: Download the repo as a ZIP FILE*
1. Navigate to `<>Code` dropdown menu
2. Select `Download ZIP`
3. Follow the prompts to save the directory

### Option B: Use GIT to CLONE the repo
1. Signup for git if you don't use it
2. Navigate to `<>Code` dropdown menu
3. Copy the URL to clone the repo OR open the repo in you Git desktop app if you use that.

### Option C: SELECT only the files you need
1. Select the MaxMSP folder
2. Select a subfolder
3. Choose a file to view
4. Download raw file (top right corner of file editor) OR copy/paste the code into Max
